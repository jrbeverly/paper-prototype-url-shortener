# Documentation

This directory contains project documentation for the short-io-url-shortener platform. Documentation is the source of truth per the repository's docs-driven development philosophy.

## Directory Structure

| Directory | Purpose |
|---|---|
| [api/](api/) | External API documentation for customers and integrators |
| [decisions/](decisions/) | Architecture Decision Records (ADRs) in CLOD-MD format |
| [vision/](vision/) | Long-term vision documents for major efforts |
| [plans/](plans/) | Implementation plans for multi-phase features |

## Quick Reference

- **External API docs** → [api/README.md](api/README.md) — quickstart, reference, auth, errors, rate limits
- **Architecture decisions** → [decisions/README.md](decisions/README.md) — index of all ADRs with decision map
- **Feature visions** → [vision/README.md](vision/README.md) — multi-session direction documents
- **Implementation plans** → [plans/README.md](plans/README.md) — phased implementation plans

## Templates

- [ADR template](decisions/_template.md) — CLOD-MD format for architecture decisions
- [Vision document template](vision/_template.md) — Long-term vision and approach
