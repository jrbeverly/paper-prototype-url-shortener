# Implementation Plans

This directory contains staged implementation plans for multi-phase features. Plans break large tasks into reviewable phases, enabling the stop/check/refine workflow.

## Purpose

Plan documents enable:
- Incremental implementation with user review between phases
- Decision capture and rationale that persists across sessions
- Claude to resume work across sessions with full context

## When to Create

Create a plan document when:
- The task spans multiple phases or sessions
- User review is needed after each phase
- Decisions made during implementation should be preserved

## Template

No formal template — plans should include:
- **Goal** — What are we building?
- **Phases** — Numbered phases, each with a checkbox list, dependencies, and risks
- **Decision Log** — Decisions made during implementation with dates and rationale
