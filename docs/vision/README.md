# Vision Documents

This directory contains long-term vision documents for major efforts. Vision documents capture intent and direction outside of ephemeral chat history, enabling Claude and other developers to resume work across sessions.

## Purpose

Vision documents persist direction for:
- Multi-session features (> 1 day of work)
- Major architectural changes
- Feature roadmaps
- Migration strategies

## When to Create

Create a vision document when:
- The effort spans multiple sessions or phases
- The architecture needs a documented north star
- Trade-offs and rationale should survive beyond the current conversation

## Template

Use [\_template.md](_template.md) for new vision documents.
